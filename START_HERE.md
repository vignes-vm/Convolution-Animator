## 💡 How It Works

1. **Enter Sequences**
   - Type x[n] as comma-separated: "1,2,3"
   - Type h[n] as comma-separated: "5,6,7"
   - Click "Start Animation"

2. **Watch Animation**
   - Sequences highlight overlapping elements
   - Products calculated for each step
   - Animation auto-plays
   - Output updates in real-time

3. **Control Playback**
   - Pause to examine current step
   - Use Previous/Next to step through
   - Adjust speed as needed
   - Enter new sequences anytime

## 🔬 Example: x=[1,2,3], h=[5,6,7]

```
Step 0: y[0] = 1×5 = 5
Step 1: y[1] = 1×6 + 2×5 = 16
Step 2: y[2] = 1×7 + 2×6 + 3×5 = 34
Step 3: y[3] = 2×7 + 3×6 = 32
Step 4: y[4] = 3×7 = 21

Output: y = [5, 16, 34, 32, 21]
```

Watch this exact process animated step-by-step!
